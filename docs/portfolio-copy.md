**Identity & Access Management Lab** | Python, RBAC, GitHub Actions, CSV | [GitHub](https://github.com/trustz3ro/identity-access-management-lab)

- Built a Python RBAC access review that compares simulated group memberships with approved job roles and flags direct assignments, retained access for departing users, and other access exceptions.
- Developed a non-destructive joiner, mover, and leaver planner that validates lifecycle requests and generates proposed account, OU, and group actions for three sample events.
- Integrated identity validation, access review, and lifecycle planning into GitHub Actions, publishing repeatable CSV reports as workflow artifacts.
