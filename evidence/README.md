This folder will contain screenshots and validation evidence from the hands-on IAM lab.

## Planned Evidence

- Active Directory Organizational Unit structure
- Security group creation
- Sample user provisioning
- User group membership validation
- Joiner test
- Mover test
- Leaver test
- PowerShell automation output
- Python access-review output
- Access exceptions and remediation

## Evidence Guidelines

Screenshots should demonstrate the security control being tested rather than only showing that a command was run.

Before publishing evidence:

- Remove real credentials and secrets.
- Use only fictional identity information.
- Avoid exposing IP addresses or configuration details that could create unnecessary security risk.
- Add a short explanation describing what each screenshot proves.
